# UI 交互测试用例

## 测试环境准备

```bash
# 启动后端服务
cd ai-pro
go run cmd/server/main.go

# 启动前端开发服务
cd web
npm run dev

# 访问地址
http://localhost:5173
```

## 1. 语义化提炼功能 - UI 交互测试

### 测试用例 1.1: AI 深度解读区块显示

**前置条件:**
- 已登录系统
- 至少有一台主机可用

**操作步骤:**

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 点击顶部主机选择器 | 显示主机下拉列表 |
| 2 | 选择一台主机（如 server-001） | 主机选择器显示已选主机，右侧面板显示监控图表 |
| 3 | 在输入框输入 "检查磁盘使用情况" | 输入框显示文字 |
| 4 | 按 Enter 或点击发送按钮 | 消息发送，显示用户消息气泡 |
| 5 | 等待 AI 响应 | 显示 "思考中..." 动画 |
| 6 | 工具执行完成 | 显示工具卡片，左侧边框为绿色（成功） |
| 7 | 观察工具卡片下方 | 显示 "AI 深度解读" 区块，带蓝色渐变背景 |
| 8 | 观察解读内容 | 显示加载动画 "正在分析..." |
| 9 | 分析完成 | 显示风险等级标签、摘要、建议等 |

**截图验证点:**
```
┌─────────────────────────────────────────┐
│ 🔧 check_disk                    [成功] │
├─────────────────────────────────────────┤
│ Filesystem  Size  Used  Use%           │
│ /dev/sda1   100G  77G   77%            │
├─────────────────────────────────────────┤
│ ✨ AI 深度解读              [需关注]   │
│ ┌─────────────────────────────────────┐ │
│ │ ⚠️ /dev/sda1 占用 77%，建议关注    │ │
│ │ 📈 过去24小时增长约5%              │ │
│ │ 💡 建议清理 /var/log 目录          │ │
│ │ ┌────────┐ ┌────────┐              │ │
│ │ │根分区   │ │数据分区│              │ │
│ │ │77% 正常 │ │90% 警告│              │ │
│ │ └────────┘ └────────┘              │ │
│ └─────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

### 测试用例 1.2: 风险等级颜色验证

**操作步骤:**

| 场景 | 输入命令 | 预期风险等级 | 预期颜色 |
|------|----------|-------------|----------|
| 正常 | "检查 CPU" (结果 < 70%) | 正常 | 绿色标签 |
| 警告 | "检查磁盘" (结果 > 85%) | 需关注 | 黄色标签 |
| 危急 | "检查内存" (可用 < 1GB) | 需立即处理 | 红色标签 |

### 测试用例 1.3: 解读区块折叠/展开

**操作步骤:**

| 2 | 再次点击标题栏 | 内容区域展开，箭头图标恢复 |

## 7. 端到端流程测试

### 测试用例 7.1: 完整磁盘告警处理流程

**操作步骤:**

```
步骤 1: 登录系统
        → 进入聊天页面

步骤 2: 选择主机
        → 点击主机选择器
        → 选择 "server-001"
        → 右侧面板显示监控图表

步骤 3: 检查磁盘
        → 输入 "检查磁盘使用情况"
        → 按 Enter 发送
        → 等待工具执行

步骤 4: 查看 AI 解读
        → 工具卡片显示执行结果
        → AI 深度解读显示 "需关注"
        → 显示磁盘使用率和建议

步骤 5: 查看历史关联
        → 历史关联卡片显示
        → 显示 "3天前出现过类似问题"
        → 显示历史解决方案

步骤 6: 查看推荐操作
        → 右侧智能操作面板更新
        → "清理缓存" 显示为 AI 推荐
        → 显示 85% 置信度

步骤 7: 执行推荐操作
        → 点击 "清理缓存"
        → 确认对话框（如需要）
        → 发送清理命令

步骤 8: 验证结果
        → AI 执行清理操作
        → 再次检查磁盘
        → 确认空间已释放
```
