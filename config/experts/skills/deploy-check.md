# 部署前检查

在执行部署前，请完成以下检查：

## 检查项目

1. **系统资源检查**
   - CPU 使用率是否低于 80%
   - 内存使用率是否低于 85%
   - 系统负载是否正常

2. **磁盘空间检查**
   - 根分区剩余空间是否大于 20%
   - 应用目录是否有足够空间

3. **服务状态检查**
   - 关键服务是否正常运行
   - 数据库连接是否正常
   - 网络连接是否正常

4. **备份确认**
   - 数据库是否已备份
   - 配置文件是否已备份

## 输出格式

请以表格形式输出检查结果，标注每项的状态（✅ 通过 / ⚠️ 警告 / ❌ 失败）。

如果有任何检查项失败，请给出具体的修复建议。
